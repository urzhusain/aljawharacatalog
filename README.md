# Al Jawhara · Item Catalogue

Open the page, type an item name/code or tap **Scan** to read a label barcode, and see the item photo and price.

- `index.html` – the page
- `items.json` – item list (name, SKU, price, category, photo)
- `img/` – item photos
- `js/html5-qrcode.min.js` – barcode scanner library (Apache-2.0, see `js/html5-qrcode.LICENSE`)
